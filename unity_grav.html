1단계: 필수 준비물 챙기기

본격적인 연동을 위해 안티그래비티 IDE와 Git(깃) 두 가지 프로그램이 꼭 필요해요!

안티그래비티 IDE

  • AI 에이전트가 내장된 똑똑한 코드 에디터예요.
  • 운영체제에 맞는 버전을 다운로드하고 설치해 주세요.
IDE 다운로드

Git (깃)

  • 유니티가 연동 패키지를 가져올 때 꼭 필요해요.
  • 이미 있다면 패스! 없다면 다운로드 후 계속 'Next'만 눌러서 설치하세요.
Git 다운로드

잠깐! 가장 중요해요

방금 프로그램을 새로 설치했다면, 컴퓨터가 제대로 인식할 수 있도록 유니티 에디터와 유니티 허브를
완전히 껐다가 다시 켜주세요! (창 닫기 버튼을 누른 뒤, 허브까지 재실행해야 합니다.)

2단계: 유니티에 패키지 설치하기

유니티 에디터가 안티그래비티를 인식할 수 있게 특수 패키지를 설치할 거예요.

1

Package Manager 열기

유니티 상단 메뉴에서
Window > Package Manager
를 클릭하세요.

2

Git URL로 추가하기

창 왼쪽 위 + 버튼을 누르고
Add package from git URL...
을 선택하세요.

3

주소 복사해서 붙여넣기

아래 주소를 복사해서 붙여넣고 Add를 누르세요.

https://github.com/TermWay/unity-ide-antigravity.git

복사 완료!

3단계: 기본 에디터로 설정하기

코드를 더블클릭했을 때 안티그래비티가 열리도록 연결합니다. 가장 중요한 핵심 단계예요!

1 설정 창 열기

메뉴에서 Edit > Preferences
(맥은 Unity > Settings)를 열고
왼쪽 탭에서 External Tools를 클릭하세요.

2 에디터 선택

External Script Editor 항목을 클릭하고 Antigravity를 선택하세요.

목록에 없다면 Browse를 눌러 실행 파일을 직접 찾아주세요.

3 파일 갱신!

아래 체크박스를 모두 체크하고,
Regenerate project files 버튼을 반드시 클릭하세요!

이 버튼을 눌러야 에이전트가 코드를 읽을 수 있습니다.

4단계: C# 언어 자동완성 달아주기

코드에 예쁘게 색칠해주고 명령어를 자동으로 추천해주는 확장을 안티그래비티에 설치합니다.

가장 쉬운 설치 순서

  • 1 안티그래비티 왼쪽 메뉴에서 확장(Extensions) 아이콘 클릭
  • 2 검색창에 omnisharp 이라고 검색
  • 3 결과에서 C# (OmniSharp) 이라는 오픈소스 확장을 설치
  • 4 설치 완료 후 안티그래비티를 완전히 껐다가 다시 켜기!

마소 공식 확장은 NO!

라이선스 문제로 마이크로소프트의 공식 'Unity'나 'C#' 확장을 쓰면 오류가 나고 색칠이 되지 않아요.

반드시 검색어 omnisharp을 사용하세요!

5단계: 성공 확인 및 바이브 코딩 시작!

드디어 세팅 완료! 코드를 열어서 잘 연결되었는지 두 가지만 확인해 볼까요?

1. 알록달록한 코드

코드가 하얀 단색이 아니라 파란색, 초록색 등 예쁘게 색칠(하이라이팅) 된다면 1차 합격!

2. 스마트한 자동완성

빈 줄에 GameObject.을 쳤을 때 유니티 전용 명령어들이 촤르륵 뜨면 완벽 성공!

이제 너만의 게임을 만들 시간이야!
