2단계: 유니티에 패키지 설치하기

1

매니저 열기

유니티 상단 메뉴에서
Window > Package Manager
를 클릭하세요.

2

Git URL 선택

창 왼쪽 위 + 버튼을 누르고
Add package from git URL...
을 선택하세요.

3

주소 붙여넣기

아래 주소를 복사해 넣고 Add를 누르세요.

https://github.com/TermWay/unity-ide-antigravity.git

복사 완료!

3단계: 기본 에디터로 설정하기

1

설정 창 열기

메뉴에서 Edit > Preferences를 열고
External Tools를 클릭하세요.

2

에디터 선택

External Script Editor에서
Antigravity를 선택하세요.

(목록에 없으면 Browse로 직접 찾기)

3

파일 갱신!

체크박스를 모두 체크하고, 아래
Regenerate project files
버튼을 반드시 누르세요!

4단계: C# 언어 자동완성 달아주기

가장 쉬운 설치 순서

  • 1 안티그래비티 왼쪽 메뉴 확장(Extensions) 클릭
  • 2 검색창에 omnisharp 검색
  • 3 결과에서 C# (OmniSharp) 이라는 오픈소스 확장을 설치
  • 4 설치 후 안티그래비티 완전히 껐다가 켜기!

마소 공식 확장은 NO!

마이크로소프트의 공식 'Unity'나 'C#' 확장을 쓰면 오류가 나고 색칠이 안 돼요.

반드시 omnisharp으로 검색하세요.

5단계: 성공 확인 및 바이브 코딩 시작!

1. 알록달록한 코드

코드가 하얀 단색이 아니라 파란색, 초록색 등 예쁘게 색칠(하이라이팅) 된다면 1차 합격!

2. 스마트한 자동완성

빈 줄에 GameObject.을 쳤을 때 명령어들이 촤르륵 뜨면 완벽 성공!
