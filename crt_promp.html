🚀 제미나이에서 챗봇 만들기 실습 가이드

            
오른쪽 창의 '시스템 프롬프트'를 복사해 두었나요? 이제 아래 순서대로 제미나이에 붙여넣기만 하세요!

        


        

            
            

                

                    
1. 제미나이에게 기획자 역할 부여하기

                    
                

                
제미나이에게 질문할 때 객관식으로 물어보도록 지시합니다. 숫자로만 편하게 대답하세요.

                


너는 나와 함께 웹 서비스를 만드는 개발 파트너야.
나는 코딩이 처음인 중학생이야. 어려운 용어는 풀어서 설명해 줘.

우리는 '청소년 금융 도우미 챗봇'의 화면(UI)을 먼저 기획할 거야. 
화면을 더 구체적으로 정하기 위해 나에게 필요한 질문을 하나씩 해 줘.

[중요 규칙]
1. 나에게 질문할 때는 주관식이 아니라, 항상 1~5번까지 객관식 보기를 함께 제시해 줘.
2. 나는 숫자만 타이핑해서 대답할게.
3. 내가 숫자로 대답하면 다음 기획 질문으로 넘어가 줘.

                

            


            
            

                

                    
2. 챗봇 화면 만들기 (프롬프트 적용)

                    
                

                
문답 기획이 끝나면, 앞서 우리가 만든 '시스템 프롬프트'를 붙여넣어 화면을 완성합니다.

                


우리가 나눈 기획 대화를 바탕으로 '청소년 금융 도우미 챗봇' 웹 앱을 만들어 줘.

- 디자인: 다크 모드, 깔끔한 카드형 UI, 따뜻한 파스텔 톤 포인트 색상 적용
- 동작: 사용자가 메시지를 보내면 화면 안에서 AI가 아래 [시스템 프롬프트] 규칙에 맞춰 바로 답변하도록 구현해 줘.

[시스템 프롬프트]
(※ 여기에 아까 복사해둔 시스템 프롬프트를 붙여넣으세요! ※)

                

            


            
            

                

                    
3. 편의 기능(버튼) 추가하기

                    
                

                
화면이 만들어졌다면, 클릭하기 쉽게 자주 묻는 질문 버튼을 추가해 봅니다.

                


방금 만든 챗봇 대화창 위쪽에 자주 묻는 질문 버튼 3개를 추가해 줘.
- 버튼 1: 적금이 뭐야?
- 버튼 2: 체크카드 어떻게 써?
- 버튼 3: 이 문자 스미싱이야?

버튼을 누르면 해당 질문이 자동으로 입력창에 들어가고 바로 전송되도록 해 줘.
