📖 SET 규칙 배우기

SET(셋)은 3장의 카드를 찾는 게임이에요.

카드에는 4가지 특징이 있어요.

  • 모양: 타원, 다이아몬드, 물결
  • 색깔: 빨강, 초록, 보라
  • 개수: 1개, 2개, 3개
  • 색칠: 꽉 참, 빗금, 비어있음

✨ 세트(SET)가 되려면?

3장의 카드가 가진 4가지 특징이 각각 "모두 같거나" 혹은 "모두 달라야" 해요!

주의! 2개는 같고 1개가 다르면 세트가 아니에요!
