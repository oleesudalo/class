01

변수

값에 이름을 붙여 저장하는 상자

쉽게 이해하기

변수는 데이터를 잠시 저장해 두는 이름표가 붙은 상자입니다. = 기호의 오른쪽 값을 왼쪽 변수에 저장합니다.

score = 80
name = "민수"
price = 2000

※ Python의 =는 “같다”가 아니라 “저장한다”에 가깝습니다.

변수가 필요한 이유

값이 바뀌어도 같은 코드를 다시 사용할 수 있습니다.

num = 4
result = num * num
print(result)   # 16
시험 포인트: 숫자를 직접 다시 쓰지 말고, 이미 주어진 변수로 계산하는 문제가 자주 나옵니다.

변수는 왜 사용할까요?

변수는 값을 저장해 두는 이름표가 붙은 상자라고 생각하면 쉽습니다.

예를 들어 점수가 80점이라면 score = 80이라고 쓰고, 이후에는 숫자 80 대신 score라는 이름을 사용합니다.

  • score = 80 → score라는 변수에 80 저장
  • score = 90 → 기존 값이 90으로 바뀜
  • print(score) → 변수에 저장된 값 출력
기억하기: Python에서 =는 “같다”보다 “오른쪽 값을 왼쪽에 저장한다”라고 이해하는 것이 좋습니다.

변수 이름을 정할 때

변수 이름은 값이 무엇을 뜻하는지 알 수 있게 정하면 코드를 읽기 쉬워집니다.

좋은 예이유

student_name학생 이름이라는 뜻이 분명함
total_price총 가격이라는 뜻이 잘 드러남

02

입력 · 출력

input()으로 받고, print()로 보여주기

입력: input()

input()은 사용자가 키보드로 입력한 값을 받습니다. 중요한 점은 입력 결과가 기본적으로 문자열(str)이라는 것입니다.

age = input("나이를 입력하세요: ")
print(age)

숫자로 계산하려면

n = int(input("정수를 입력하세요: "))
print(n + 10)

input → int 변환 → 계산 순서를 익혀두세요.

① 입력→② 처리→③ 출력

입력과 출력은 무엇인가요?

프로그램은 보통 입력 → 처리 → 출력의 순서로 동작합니다.

  • 입력: 사용자가 값을 넣음 → input()
  • 처리: 입력한 값을 계산하거나 비교함
  • 출력: 결과를 화면에 보여줌 → print()
name = input("이름: ")
print("안녕하세요", name)

input()에서 가장 중요한 점

input()으로 받은 값은 항상 문자열(str)입니다.

따라서 숫자 계산을 하려면 먼저 숫자 자료형으로 바꿔야 합니다.

age = input("나이: ")
print(type(age))   # str

age = int(age)
print(age + 1)
자주 나오는 실수: input()으로 받은 숫자를 바로 더하려고 하면 문자열이라 계산이 원하는 방식으로 되지 않을 수 있습니다.

자료형

값의 종류를 구분해야 연산이 정확해짐

자료형뜻예형변환

str문자열"사과", "10"str(10)

형변환이 필요한 상황

s = "10"
n = 10
check = int(s) == n
print(check)   # True

bool() 주의

bool("")       # False
bool("사과")   # True
bool(0)        # False
bool(1)        # True

비어 있는 문자열은 False, 내용이 있는 문자열은 True로 판단됩니다.

자료형이란?

자료형은 데이터의 종류입니다. 값의 종류에 따라 할 수 있는 연산이 달라집니다.

자료형예설명
int10, -3소수점이 없는 정수
float3.14, 0.5소수점이 있는 실수
str"사과", "10"글자나 문장
boolTrue, False참 또는 거짓

형변환은 왜 하나요?

자료형이 다르면 원하는 계산이 되지 않을 수 있어 자료형을 바꾸는 과정이 필요합니다.

num = "10"       # 문자열
num = int(num)    # 정수로 변경

rate = "0.5"
rate = float(rate)

age = 10
text = str(age)

연산자는 어떤 일을 하나요?

연산자는 값을 계산하거나 비교할 때 사용하는 기호입니다.

특히 시험에서는 %, ==, !=, +=가 자주 등장합니다.

  • == → 두 값이 같은지 비교

score == 90       # 비교 → True

문자열 슬라이싱

문자열에서 원하는 부분만 잘라서 가져오는 방법입니다. 대괄호 안에 [시작:끝] 형태로 작성합니다.

text = "Python"

print(text[0:2])   # Py
print(text[2:6])   # thon
print(text[:3])    # Pyt
print(text[3:])    # hon
표현뜻
text[0]첫 번째 글자 1개 가져오기
text[1:4]1번부터 3번 위치까지 가져오기
text[:3]처음부터 2번 위치까지 가져오기
text[3:]3번 위치부터 끝까지 가져오기
중요: 슬라이싱의 끝 번호는 포함되지 않습니다. text[1:4]는 1, 2, 3번 위치의 글자만 가져옵니다.

문자열은 무엇인가요?

문자열은 글자나 문장의 모음이며 따옴표로 묶어서 표현합니다.

name = "민수"
word = "Python"
number_text = "123"

"123"은 숫자처럼 보여도 따옴표가 있으므로 문자열입니다.

문자열에서 한 글자 꺼내기

문자열도 리스트처럼 0번부터 번호를 붙여 한 글자씩 가져올 수 있습니다.

text = "Python"

print(text[0])   # P
print(text[1])   # y
print(text[-1])  # n
기억하기: 첫 번째 글자의 번호는 1이 아니라 0입니다.

함수 문제를 풀 때 보는 3가지

① 매개변수는 무엇인가? ② 함수 안에서 무엇을 계산하는가? ③ return 값이 어디에 저장되는가?

함수는 왜 사용하나요?

함수는 자주 사용하는 코드를 이름을 붙여 묶어 둔 것입니다.

같은 코드를 여러 번 작성하지 않아도 되고, 프로그램을 기능별로 나눌 수 있어 읽기 쉬워집니다.

함수의 4단계

  1. def로 함수를 만든다.
  2. 필요하면 값을 받을 매개변수를 적는다.
  3. 함수 안에서 계산한다.
  4. return으로 결과를 돌려준다.
def add(a, b):
    result = a + b
    return result

answer = add(3, 5)
print(answer)

매개변수와 인자, 어렵게 생각하지 않기

def add(a, b)의 a, b는 함수가 받을 값을 담아 둘 자리입니다.

add(3, 5)처럼 실제 값을 넣어 호출하면, a에는 3, b에는 5가 들어갑니다.

기억하기: return은 결과를 화면에 보여주는 것이 아니라, 함수 밖으로 결과값을 돌려주는 것입니다.
