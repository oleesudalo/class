먼저 알아둘 용어

용어뜻예시

콜백 함수특정 상황에 Unity가 자동 호출하는 함수Start(), Update(), OnTriggerEnter2D()

1. 2D 이동 · Rigidbody2D

키보드 입력을 받아 Rigidbody2D의 속도에 적용하는 기본 이동 방식입니다.
기본 작성법
float x = Input.GetAxisRaw("Horizontal");
float y = Input.GetAxisRaw("Vertical");

Vector2 move = new Vector2(x, y).normalized;
rb.linearVelocity = move * moveSpeed;
주요 값
"Horizontal"stringA/D 또는 ←/→ 입력 축
"Vertical"stringW/S 또는 ↑/↓ 입력 축
moveSpeedfloat직접 만든 이동속도 변수
.normalizedVector2대각선 이동이 빨라지는 현상을 방지
포인트: Rigidbody2D 기반 이동과 Transform 직접 이동을 무작정 섞지 않는 편이 좋습니다.

2. OnTriggerEnter2D · CompareTag

플레이어가 아이템·함정·도착지 같은 Trigger 영역에 들어왔을 때 실행됩니다.
기본 작성법
private void OnTriggerEnter2D(Collider2D other)
{
  if (other.CompareTag("Item"))
  {
    score += 1;
    Destroy(other.gameObject);
  }
}
매개변수
otherCollider2D내 Trigger에 들어온 상대의 Collider
"Item"string(Tag)Inspector에서 설정한 태그 이름
조건: Collider2D 중 하나는 Is Trigger가 켜져 있어야 하며, 충돌 쌍 중 적어도 하나에는 Rigidbody2D가 필요합니다.

3. Instantiate()

총알, 적, 상자, 아이템처럼 게임 도중 새 오브젝트를 만들어낼 때 사용합니다.
기본 작성법
Instantiate(prefab, spawnPoint.position, spawnPoint.rotation);
매개변수
prefabGameObject복제할 원본 프리팹
positionVector3생성할 위치
rotationQuaternion생성할 회전값
자주 쓰는 값: 회전이 필요 없으면 Quaternion.identity를 사용합니다.

4. Destroy()

총알, 적, 먹은 아이템 등 더 이상 필요 없는 오브젝트를 삭제합니다.
기본 작성법
Destroy(gameObject);
Destroy(gameObject, 2f);
매개변수
gameObjectObject삭제할 대상
2ffloat선택 사항. 몇 초 뒤 삭제할지 지정
예: 총알은 Destroy(gameObject, 3f)로 자동 정리하면 좋습니다.

5. Physics.Raycast()

보이지 않는 광선을 쏴 무엇에 맞았는지 검사합니다. FPS 총, 상호작용, 시야 판정에 자주 씁니다.
기본 작성법
if (Physics.Raycast(origin, direction, out RaycastHit hit, distance))
{
  Debug.Log(hit.collider.name);
}
매개변수
originVector3광선 시작 위치
directionVector3광선 방향
hitRaycastHit맞은 대상 정보를 담는 변수
distancefloat최대 검사 거리
FPS: 보통 카메라 위치와 camera.transform.forward를 사용합니다.

6. SceneManager.LoadScene()

타이틀 → 게임 → 결과처럼 Scene을 이동할 때 사용합니다.
기본 작성법
using UnityEngine.SceneManagement;

SceneManager.LoadScene("GameScene");
매개변수
"GameScene"string불러올 Scene 이름
0, 1, 2...intBuild Settings 순번을 사용할 수도 있음
주의: Scene이 Build Settings에 등록되어 있어야 합니다.

7. TMP_Text · Slider · SetActive()

점수, HP, 남은 시간, 게임오버 패널 같은 UI를 변경합니다.
기본 작성법
scoreText.text = "Score : " + score;
hpSlider.value = currentHp;
gameOverPanel.SetActive(true);
주요 값
.textstringTextMeshPro에 표시할 글자
.valuefloatSlider의 현재 값
true / falsebool오브젝트 활성화 / 비활성화
TMP: 스크립트 상단에 using TMPro;를 추가합니다.

8. List<T> · 배열 · enum

아이템, 버프, 마작패, 룬처럼 여러 데이터를 묶어서 관리할 때 사용합니다.
기본 작성법
List<GameObject> items = new List<GameObject>();

items.Add(newItem);
items.Remove(oldItem);

public enum RoomType { Battle, Shop, Boss }
자주 쓰는 기능
Add(value)method리스트 끝에 데이터 추가
Remove(value)method해당 데이터 제거
Countint리스트 데이터 개수
enumtype정해진 상태 이름을 묶어 관리

9. Random.Range()

랜덤 보상, 적 위치, 아이템 선택 등에 사용합니다.
기본 작성법
int index = Random.Range(0, items.Count);
float x = Random.Range(-5f, 5f);
매개변수 차이
int, int0, 50 이상 5 미만 → 0~4
float, float0f, 5f0~5 범위의 실수
중요: 정수형은 최대값이 포함되지 않습니다.

10. Coroutine · WaitForSeconds

몇 초 기다렸다 실행, 공격 딜레이, 함정 지연, 웨이브 생성 등에 사용합니다.
기본 작성법
IEnumerator ShowTrap()
{
  yield return new WaitForSeconds(1f);
  wall.SetActive(true);
}

StartCoroutine(ShowTrap());
주요 요소
IEnumeratorreturn typeCoroutine 함수 선언
1ffloat기다릴 시간(초)
StartCoroutine()methodCoroutine 실행

11. GetComponent<T>()

GameObject에 붙어 있는 다른 컴포넌트나 스크립트를 가져와 사용할 때 씁니다.
기본 작성법
EnemyHealth hp = hit.collider.GetComponent<EnemyHealth>();

if (hp != null)
  hp.TakeDamage(10);
형식
<T>Type가져올 컴포넌트 타입
반환값T 또는 null있으면 컴포넌트, 없으면 null
팁: Update에서 매 프레임 찾기보다는 Start에서 받아 변수에 저장하는 것이 일반적입니다.

12. ScriptableObject

무기·아이템·직업·룬처럼 데이터 종류가 많아질 때 데이터를 Asset으로 분리해 관리합니다.
기본 작성법
[CreateAssetMenu(menuName = "Game/WeaponData")]
public class WeaponData : ScriptableObject
{
  public string weaponName;
  public int damage;
  public float attackSpeed;
}
추천 대상: 장비와 버프가 많은 전이준, 시스템이 복잡한 박윤수·조민교 프로젝트에 특히 유용합니다.

13. 2차원 배열 [,]

격자형 퍼즐이나 보드게임에서 x, y 위치별 상태를 저장합니다.
기본 작성법
int[,] board = new int[8, 8];

board[2, 3] = 1;

if (board[x, y] == 0)
  Debug.Log("빈칸");
인덱스
첫 번째 값x가로 위치
두 번째 값y세로 위치
임인수 프로젝트: 화면 블록과 board 배열 상태를 항상 같이 갱신해야 합니다.

14. Quaternion.Euler · Time.deltaTime

오브젝트 회전과 프레임 독립적인 시간 기반 움직임에 사용합니다.
기본 작성법
angle += rotateSpeed * Time.deltaTime;
transform.rotation = Quaternion.Euler(0, 0, -angle);
Quaternion.Euler 매개변수
xfloatX축 회전 각도
yfloatY축 회전 각도
zfloat2D에서 주로 사용하는 Z축 각도
Time.deltaTime: PC 성능이나 FPS가 달라도 초당 움직임을 비슷하게 유지하도록 도와줍니다.
