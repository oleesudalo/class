1. 2D 이동 · Rigidbody2D

키보드 입력을 받아 Rigidbody2D의 속도에 적용하는 기본 이동 방식입니다.
기본 작성법
float x = Input.GetAxisRaw("Horizontal");
float y = Input.GetAxisRaw("Vertical");

Vector2 move = new Vector2(x, y).normalized;
rb.linearVelocity = move * moveSpeed;
주요 값
"Horizontal"stringA/D 또는 ←/→ 입력 축
"Vertical"stringW/S 또는 ↑/↓ 입력 축
moveSpeedfloat직접 만든 이동속도 변수
.normalizedVector2대각선 이동이 빨라지는 현상을 방지
포인트: Rigidbody2D 기반 이동과 Transform 직접 이동을 무작정 섞지 않는 편이 좋습니다.

2. 3D 이동 · CharacterController

FPS나 3D 탐험에서 충돌을 유지하며 이동할 때 사용합니다.
기본 작성법
Vector3 move = transform.right * x + transform.forward * z;
controller.Move(move.normalized * moveSpeed * Time.deltaTime);
주요 값 / 매개변수
moveVector3이동 방향
moveSpeedfloat이동 속도
Time.deltaTimefloat프레임 보정
포인트: CharacterController.Move는 중력을 자동 적용하지 않으므로 필요하면 gravity를 별도로 계산합니다.

3. 점프 · Ground Check

바닥에 있을 때만 점프하도록 검사하고 Rigidbody2D에 위쪽 힘을 줍니다.
기본 작성법
bool isGrounded = Physics2D.OverlapCircle(groundCheck.position, groundRadius, groundLayer);
if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
rb.AddForce(Vector2.up * jumpPower, ForceMode2D.Impulse);
주요 값 / 매개변수
groundCheck.positionVector2바닥 검사 위치
groundRadiusfloat검사 반경
groundLayerLayerMask바닥 레이어
jumpPowerfloat점프 힘
포인트: Ground Check가 없으면 공중에서 무한 점프가 생기기 쉽습니다.

4. 충돌 · Trigger · CompareTag

플레이어가 아이템·함정·도착지 같은 Trigger 영역에 들어왔을 때 실행됩니다.
기본 작성법
private void OnTriggerEnter2D(Collider2D other)
{
  if (other.CompareTag("Item"))
  {
    score += 1;
    Destroy(other.gameObject);
  }
}
매개변수
otherCollider2D내 Trigger에 들어온 상대의 Collider
"Item"string(Tag)Inspector에서 설정한 태그 이름
조건: Collider2D 중 하나는 Is Trigger가 켜져 있어야 하며, 충돌 쌍 중 적어도 하나에는 Rigidbody2D가 필요합니다.

5. Instantiate()

총알, 적, 상자, 아이템처럼 게임 도중 새 오브젝트를 만들어낼 때 사용합니다.
기본 작성법
Instantiate(prefab, spawnPoint.position, spawnPoint.rotation);
매개변수
prefabGameObject복제할 원본 프리팹
positionVector3생성할 위치
rotationQuaternion생성할 회전값
자주 쓰는 값: 회전이 필요 없으면 Quaternion.identity를 사용합니다.

6. Destroy()

총알, 적, 먹은 아이템 등 더 이상 필요 없는 오브젝트를 삭제합니다.
기본 작성법
Destroy(gameObject);
Destroy(gameObject, 2f);
매개변수
gameObjectObject삭제할 대상
2ffloat선택 사항. 몇 초 뒤 삭제할지 지정
예: 총알은 Destroy(gameObject, 3f)로 자동 정리하면 좋습니다.

7. Raycast · LayerMask

보이지 않는 광선을 쏴 무엇에 맞았는지 검사합니다. FPS 총, 상호작용, 시야 판정에 자주 씁니다.
기본 작성법
if (Physics.Raycast(origin, direction, out RaycastHit hit, distance))
{
  Debug.Log(hit.collider.name);
}
매개변수
originVector3광선 시작 위치
directionVector3광선 방향

distancefloat최대 검사 거리
FPS: 보통 카메라 위치와 camera.transform.forward를 사용합니다.

8. HP · Damage · TakeDamage

총·근접·함정의 피해 처리를 한 함수로 통일하는 기본 전투 패턴입니다.
기본 작성법
public int maxHp = 100;
public int currentHp;

public void TakeDamage(int damage)
{
currentHp -= damage;
if (currentHp <= 0) Die();
}
주요 값 / 매개변수
maxHpint최대 체력
currentHpint현재 체력
damageint받는 피해량
포인트: 여러 공격 코드가 currentHp를 직접 수정하기보다 TakeDamage()를 호출하도록 통일하면 관리가 쉽습니다.

17. GetComponent<T>()

GameObject에 붙어 있는 다른 컴포넌트나 스크립트를 가져와 사용할 때 씁니다.

형식

팁: Update에서 매 프레임 찾기보다는 Start에서 받아 변수에 저장하는 것이 일반적입니다.

18. ScriptableObject

무기·아이템·직업·룬처럼 데이터 종류가 많아질 때 데이터를 Asset으로 분리해 관리합니다.

21. 마우스 조준 · ScreenToWorldPoint

탑다운 슈팅에서 마우스 화면 좌표를 월드 좌표로 바꿔 조준 방향을 계산합니다.
기본 작성법
Vector3 mouse = Camera.main.ScreenToWorldPoint(Input.mousePosition);
Vector2 dir = mouse - transform.position;
float angle = Mathf.Atan2(dir.y, dir.x) * Mathf.Rad2Deg;
transform.rotation = Quaternion.Euler(0, 0, angle);
주요 값 / 매개변수
Input.mousePositionVector3화면 마우스 좌표
ScreenToWorldPointmethod화면→월드 변환
